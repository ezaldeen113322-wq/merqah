# حزمة تصدير تطبيق «مِرقاة» إلى تطبيق هاتف (APK / PWA)

تحتوي هذه الحزمة على كافة الملفات الجاهزة لتحويل تطبيق **«مِرقاة»** (بنسخته المتصلة بالإنترنت ونظام تسجيل الدخول) إلى تطبيق أندرويد مستقل (`APK`) أو تطبيقه مباشرة على الهاتف.

## محتويات الحزمة:
- `www/index.html`: كود التطبيق الكامل (واجهة المشرف + دخول ولي الأمر برمز الطالب + الربط السحابي).
- `www/manifest.json`: ملف تعريف التطبيق للهواتف (PWA).
- `package.json` و `capacitor.config.json`: ملفات إعداد Capacitor لتغليف التطبيق إلى أندرويد.
- `.github/workflows/build-apk.yml`: ملف بناء تلقائي يتيح لك استخراج ملف `app-debug.apk` سحابياً عبر GitHub دون الحاجة لحاسوب.

## أسرع طريقة لاستخراج ملف APK من هاتفك عبر GitHub:
1. أنشئ مستودعاً جديداً على حسابك في **GitHub** (مثلاً باسم `mirqah-app`).
2. ارفع محتويات مجلد `mirqah_app_package` (بما فيها مجلد `.github`) إلى المستودع.
3. انتقل إلى تبويب **Actions** في المستودع، وستبدأ عملية البناء تلقائياً (أو اضغط **Run workflow**).
4. بعد اكتمال البناء (حوالي دقيقتين)، حمّل ملف **Mirqah-Android-APK** من قسم **Artifacts** في أسفل الصفحة وثبّته مباشرة على هاتفك.
